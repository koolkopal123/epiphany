# Epiphany

A personal hobby tracker. Single-page PWA, no backend, data stays in the browser's localStorage.

Files: index.html, manifest.json, sw.js, icon.svg, icon-192.png, icon-512.png

Hosted with GitHub Pages (Settings > Pages > Deploy from a branch > main > / (root)).

When you update index.html, also bump the CACHE name in sw.js (e.g. epiphany-v2) so installed copies refresh.
